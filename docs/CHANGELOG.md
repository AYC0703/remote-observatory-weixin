# 变更记录

本项目版本号记录于 `package.json`（当前 **1.1.0**）。以下按时间倒序记录变更，条目后附提交哈希以便追溯。

## 1.1.0 — 2026-10

### 新增

- **观测站顶盖远程控制（硬件接入）**
  在原有审批系统之上接入 ESP32 顶盖控制器，打通「提交申请 → 管理员审批 → 时段内远程开合顶盖」的完整链路。

  - **后端**：新增 `server/hardware.js` 桥接层
    - 安全联锁：开盖须落在本人已批准的申请时段内（可提前 `COVER_OPEN_GRACE_MIN` 分钟）；降雨、风速超限、设备故障、离线、正在动作一律禁止开盖
    - **关盖不设权限**——安全方向的操作任何登录用户均可执行，离线时指令排队 1 小时等待设备恢复
    - 指令队列与完整生命周期：`pending → delivered → acked / failed / rejected`，超时自动转 `expired` / `timeout`
    - **非对称有效期**：开盖指令 90 秒过期，关盖指令 1 小时（开盖有时效性，关盖越早越好）
    - 自动策略：降雨兜底关盖；申请时段结束（含 `COVER_CLOSE_GRACE_MIN` 宽限）后自动关盖，可用 `COVER_AUTO_CLOSE=false` 关闭
    - **失联时绝不自动关盖**，只告警——避免毁掉正在进行的整晚曝光
    - 通信模型为设备主动 HTTP 长轮询，新指令入队时通过进程内事件立即唤醒挂起的请求，无需 MQTT broker 或公网 IP
  - **数据库**：新增 `cover_devices`（设备令牌与实时状态）、`cover_commands`（指令队列）、`cover_events`（设备事件流水）、`cover_telemetry`（环境采样历史）四张表与三个高频索引；设备重命名级联、删除清理绑定
  - **API**：新增 13 个接口
    - 用户端：观测站列表（含后端算好的 `can_open` / `can_close` 与拒绝原因）、单台详情、下发指令、紧急关盖
    - 管理端：接入总览、绑定 / 重置令牌、启停、解绑、管理员强制通道
    - 设备端（`X-Device-Token` 鉴权，与用户令牌完全隔离）：长轮询取指令、上报状态、指令回执、事件上报
  - **小程序**：新增「观测站控制」页面（`pages/console`）
    - 实时状态卡片（顶盖位置、在线、温湿度、风速、雨感、限位、电流、信号强度）
    - 开盖 / 关盖 / 停止 / 紧急关盖操作，按钮按后端授权结论自动置灰并展示原因
    - 管理员接入管理：生成 / 重置设备令牌、启停、解绑、管理员强制开盖
    - 指令流水与设备事件流水查看；页面隐藏时自动停止 5 秒轮询
  - **固件**：新增 `firmware/cover-controller/`
    - 状态机（IDLE / OPENING / CLOSING / FAULT）+ 限位常闭接法 + 运行超时 + 堵转过流保护
    - **关门受阻反转退让**（防夹 3 秒）、800ms PWM 软启动斜坡
    - 雨感本地硬逻辑，不依赖网络；动作期间不发起任何网络请求以保证状态机实时性
    - 上电自检（双限位冲突检测）、本地手动按钮、蜂鸣器声光警示
    - 提供 PlatformIO 工程、接线表、标定步骤与 curl 联调示例
  - **测试**：端到端测试由 72 项扩充至 112 项，新增 40 项覆盖接入鉴权、权限联锁、降雨/离线拒绝、指令全生命周期、长轮询唤醒延迟、时段自动关盖、审计留痕
  - **文档**：新增 `docs/HARDWARE_DESIGN.md`；`docs/API.md` 与 `docs/DATABASE_DESIGN.md` 同步补充

### 修复

- **自动关盖被无人回执的指令阻塞**
  自动策略原先把「任意已下发未回执的指令」都视为在途，导致一条设备失联后遗留的 `delivered` 指令会把自动关盖卡住长达 3 分钟。现改为只把「60 秒内下发的」视为在途，`pending` 仍始终视为在途。

## 1.0.0 — 2026-08

### 修复

- **管理员密码环境变量未生效**（`5f61692`）
  `ADMIN_PASSWORD` 此前仅在管理员账号首次创建时生效，已存在账号时会被静默忽略，而启动日志仍提示「密码由环境变量指定」，造成误导。现改为**每次启动同步**：密码不一致时自动更新，并输出 `[seed] 管理员密码已按 ADMIN_PASSWORD 同步更新`。

- **端口占用时输出堆栈**（`429dc74`）
  端口被占用时不再抛出 `EADDRINUSE` 堆栈，改为输出中文提示与替代启动方式（如 `PORT=3001 npm start`），并以退出码 1 结束。

### 安全

- **安全加固**（`91dea8c`）
  - 会话密钥 `SESSION_SECRET` 支持环境变量注入；未设置时启动生成 32 字节随机密钥并告警，避免硬编码密钥进入版本库
  - 管理员初始密码 `ADMIN_PASSWORD` 支持环境变量注入
  - Cookie 新增 `COOKIE_SECURE` 与 `COOKIE_SAMESITE` 配置项
  - 引入 `express-rate-limit`，登录 / 注册 / 改密接口限速（15 分钟 20 次）
  - 登录与注册成功后执行 `session.regenerate()`，防御会话固定攻击
  - CSV 导出增加公式注入防护（危险首字符前置单引号）
  - `.gitignore` 增加 `.env` 忽略规则

### 新增

- **普通用户修改密码**（`e56ba8a`）
  顶栏新增「修改密码」入口（仅普通用户可见），支持当前密码 / 新密码 / 确认新密码，并校验旧密码正确性与新密码长度。

- **观测设备管理**（`95d8251`）
  设备列表由后端硬编码改为数据库存储；管理员可新增、重命名、删除设备，支持去重校验、重命名级联更新历史申请、被引用设备删除拦截；普通用户申请表单与占用日历自动同步。

- **审计日志查看页面**（`b8602e7`）
  管理员端新增「审计日志」入口，展示最近 200 条操作流水（时间、操作人、操作类型、详情），操作类型自动翻译为中文。

### 变更

- **移动端响应式适配**（`9b3bdc1`）
  新增 720px / 480px 两级断点：表格横向滑动、导航横滑、表单与图表单列、统计卡片自适应、输入框 16px 防 iOS 聚焦缩放、触控惯性滚动。

- **移除登录页演示账号提示**（`af48fd7`）
  删除登录页底部的「演示管理员账号：admin / admin123」文本。

### 初始版本

- **项目初始实现**（`4aaed68`）
  - 双角色（普通用户 / 管理员）账号体系与登录界面
  - 普通用户：申请提交表单、实时冲突检测、我的申请列表、状态展示、撤回、状态变更时间线
  - 管理员：待审批队列（按提交时间升序）、同意 / 不同意审批（拒绝必填意见）、审批时冲突检测与强制通过、设备时段占用日历、全部申请筛选 / 搜索 / 分页、申请详情与历史
  - 统计分析：状态数量与通过率、状态分布环形图、设备申请量柱状图、月度趋势折线图、CSV 报表导出
  - 数据层：SQLite（Node 内置 `node:sqlite`）五张表（用户、申请、状态历史、审计日志、设备），申请编号自动生成，全流程留痕
  - 技术形态：Express 后端 + Vue 3 单页前端（第三方库本地化，无构建步骤），scrypt 密码哈希，参数化查询
