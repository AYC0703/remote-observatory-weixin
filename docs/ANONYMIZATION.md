# 公开版匿名化说明

本仓库是「S50 校园智能天文台」相关材料的**匿名化公开版**。

原始材料包含项目成员与指导教师的真实姓名、就读学校名称、校内楼宇名称。在公开发布前，
这些信息已被系统性替换；无法在二进制文件中脱敏的原件**未予收录**。

---

## 1. 替换对照

| 原始信息类别 | 替换为 |
| --- | --- |
| 学生负责人姓名（4 人） | `学生 A`、`学生 B`、`学生 C`、`学生 D` |
| 指导教师姓名 | `指导教师 A`、`指导教师 B` |
| 学校名称 | `某中学` |
| 校内实施地点（楼名） | `教学楼楼顶` |
| 代码托管地址 | Gitee 私有仓库 → 本 GitHub 仓库 |

> 姓名与占位符之间**不存在一一对应的公开映射**，仅在同一份文档内部保持前后一致，
> 以便读者理解「这是不同的几个人」。

## 2. 未收录的文件

| 文件 | 原因 |
| --- | --- |
| `S50立项书.pdf` | 立项书原始 PDF。姓名以字形编码嵌入页面内容流，**无法在不破坏排版的前提下脱敏**，故整份不收录。其完整内容见转写稿 [`S50立项书.md`](S50立项书.md)（已匿名化）。 |
| `整体设计初稿.mp4` | 该交付物已按项目方要求从材料中移除。 |

`docs/attachments/` 下收录的三份前期资料 xlsx 均**已做文本层脱敏**后收录。

## 4. 提交历史

本仓库的提交历史为**重建的干净历史**，不包含原私有仓库的作者信息。
原私有仓库（Gitee）保留完整历史，仅对项目成员开放。

## 5. 如需还原真实信息

在私有副本中，按下表回填即可（表中不列出真实姓名，请以私有副本中的原件为准）：

| 占位符 | 回填为 |
| --- | --- |
| `学生 A` ~ `学生 D` | 项目负责人（按原件顺序） |
| `指导教师 A` / `指导教师 B` | 指导教师 |
| `某中学` | 实际学校名称 |
| `教学楼楼顶` | 实际楼宇名称 |

## 6. 新内容的约定

向本仓库提交内容时，请遵守同样的匿名化约定：

- 文档、代码注释、提交信息、issue 中**不写入真实姓名、学校名、楼名、联系方式**
- 需要指代具体人员时，使用 `学生 A`、`指导教师 A` 这类占位符
- 含真实信息的原件表格/PDF **不要提交**，只提交脱敏后的转写稿
