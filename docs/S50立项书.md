## 二、立项依据

### 2.1 现实问题：校园天文观测的三个卡点

- **器材露天存放**——传统天文望远镜无自带防护，淋雨、锈蚀、鸟粪与枝叶刮擦会损坏镜筒与精密机构，一次维修成本往往超过整机采购预算的三成。
- **夜间值守难**——观测需要老师陪护与人工开罩、人工搬运，学生只能在特定时段"看一眼"，缺少自主设计—制作—测试的完整工程经历。
- **科普呈"演示型"**——设备买来即成品，学生与装置之间没有"造物"关系，创新素养培养落空。

### 2.2 技术条件已经成熟：S50 Pro 让"重底座"不再必要

ZWO Seestar S50 Pro 把主机、经纬仪、电机驱动、自动寻星（GoTo）、跟踪与成像全部集成一体：50mm 四片式 APO 物镜、260mm 焦距 f/5.2、双相机（OS08B10 长焦 8.3MP + IMX586 广角 8.3MP，广角视场 63°）、内置 10000mAh 电池（最长 9 小时）、128GB 存储、机内 IMU/陀螺完成自动跟踪，并开放 ASCOM/Alpaca 协议。

这意味着：望远镜自身的方位—高度角转动由机身完成，底座不需要任何赤道仪或转盘，我们只需要做一件事情——造一个能随时让开天空的"帽子"。

这正是本项目创意的起点，也是它与传统校园天文台最大的区别：结构从"重支架 + 重穹顶"简化为"轻高基座 + 一顶对开半球罩"。

### 2.3 教育政策与课标契合

- 《义务教育科学课程标准（2022 年版）》"技术与工程"领域强调"设计—制作—试验—改进"的完整实践，本项目四个阶段齐备。
- 教育部等十八部门《关于加强中小学科学教育工作的意见》鼓励利用废旧/低成本材料与校内外资源建设跨学科实践场所，并推动"做中学、用中学、创中学"。
- 项目同时覆盖初中物理（力与机械、电与磁、简单电路）、高中地理（天体与观测）、信息技术（物联网、数据与控制系统）三个学科，是天然的跨学科项目式学习载体。

### 2.4 前期基础

学生已完成：①成本清单 `costs.xlsx`；②技术问题清单 `Q&A.xlsx`（已列出 7 项待决问题）；③远程控制专项硬件选型与报价 `远程方面专项costs.xlsx`（ESP32、BTS7960、明纬电源、欧姆龙限位、雨感等）。本项目是在此基础上的工程化补全与定稿，不是从零开始。⁽ᴿ³⁾

## 三、项目目标与研究内容

### 3.1 总目标

以 ZWO Seestar S50 Pro 为核心载荷，自主设计并制作一套"高基座 + 双 1/4 半球壳对开下滑遮阳防雨罩 + ESP32 物联网远程控制"的校园智能天文台，实现"手机一点、罩开镜起、远端观测"的全流程无人值守观测，并把过程沉淀为可申报、可复现、可推广的工程方案。

### 3.2 具体目标

| 维度 | 目标表述 | 达成判据 |
| --- | --- | --- |
| 知识 | 理解半球壳对开机构的几何、直线运动传动、物联网三层架构与经纬仪跟踪原理 | 能独立口述尺寸链与推力计算过程 |
| 能力 | 会读图拆件、会选材料、会画连接节点、会写控制状态机与调试日志 | 提交 3 张工程图 + 测试记录表 |
| 工程 | 完成"设计—试制—测试—迭代"一次以上完整循环，至少 1 项结构改进 | 迭代记录 ≥1 轮且有前后对比 |
| 素养 | 形成跨学科协作（结构/电子/软件/观测/宣传）与安全防护意识 | 分工表 + 安全预案 + 反思报告 |

### 3.3 四项研究内容

- **（一）S50 Pro 安装适配与塔台本体设计**：接口、水平、供电、网络、净空的适配要求固化成安装规范。
- **（二）可开合半球罩结构设计与试制**：材料选型、分瓣方案、尺寸链校核、密封防雨、加工工艺。
- **（三）物联网远程开合与"开罩—观测"联动控制**：状态机、通信架构、三重限位、天气自动保护。
- **（四）观测数据采集、台账与校园科普应用**：成像归档、观测日志、科普课程与活动转化。

### 4.3 半球罩开合方案比选

| 方案 | 优点 | 缺点 | 评价 |
| --- | --- | --- | --- |
| 上翻铰链（合页掀开） | 结构简单、成本低 | 铰链在顶部，易渗水；开启后砸向一侧，占横向空间；大风时易回摆夹人 | 不推荐 |
| 平顶推拉（水平抽出） | 开启后水平外伸，视野好 | 需要大外圈导轨，伞骨式展开占地；阵风下侧向载荷大；雨沿外滑不好收 | 备选 |
| **对开下滑（本方案）** | 整机不动、只需竖向下滑，无高空铰链；开启后壳体整体落到赤道面以下，0°~90° 全视场零遮挡；壳体下滑后由塔身外壁承托、兼作储物 | 需竖向导轨与推力选型，加工精度要求高 | ✔ **推荐** |

说明：学生前期 Q&A 中曾判断"对开是难度最高的方案"。本项目通过把它拆解为"竖直直线下滑 + 铝型材导轨 + 自带限位的电动推杆"三个成熟模块，把难度从"曲面铰链防水"转移到"直线导向精度"上，而后者恰恰是学生最容易用铝型材和 3D 打印连接件攻克的环节。

### 4.6 驱动与传动计算

**（1）重量**：单片 1/4 球面面积 A = πR² = 0.785 m²；1.2mm 板重 2.53kg，4 根加强筋 2.18kg，五金 0.20kg → 单片 4.90kg，双片 9.80kg，单侧重载 G ≈ 48N。

**（2）风载与摩擦**：取 8m/s 风压 q=38.4Pa、投影面积 0.50 m²，F_wind ≈ 19N；导轨摩擦（μ=0.15）≈ 10N。

**（3）所需推力**：F ≥ 3 × 自重 + 风载 + 摩擦 ≈ 173N → 选用 24V / 1000N / 行程 560mm / IP65 电动推杆（安全系数 5.8×），每片球壳 1 台。

**（4）行程与速度**：S = R+20 = 520mm，推杆调至约 20mm/s → 全开约 26s，全关约 25s（指标要求 ≤40s）。

**（5）三重限位**：① 推杆内置行程开关；② 欧姆龙 SS-5GL 机械微动（全开/全关/保护位）；③ ESP32 行程计数 + 60s 超时看门狗 + INA226 电流 >3A 持续 2s 断电保护。

**（6）电源容量**：2 台推杆堵转峰值 240W + 控制 24W + 望远镜驻留 22W ≈ 286W → 原清单 LRS-150-24 仅 150W 会欠压，升级为明纬 LRS-350-24（修正项）。

### 4.7 电气控制硬件清单

沿用学生前期选型（ESP32-S3-DevKitC-1、BTS7960/IBT-2 43A、欧姆龙 SS-5GL、INA226、EL817 光耦、IP65 接线盒、急停按钮等），并按 4.6 修正电源规格，新增风速/温湿/光照三合一传感器。详见配套《经费预算明细表》第五类。

### 4.8 物联网架构与通信（回应前期 Q&A 第 2、3 问）

- **不在校园里自建服务器、不占用学校小程序/后端资源。** 控制端直接用 ESP32-S3 固化的 MQTT 客户端，接入公共 MQTT Broker（如巴法云或 EMQX 公共节点）；学生终端用网页面板/MQTT 客户端/校园小程序（前端直连 Broker）均可，无需后端托管。
- **望远镜侧**：S50 Pro 自带 Wi-Fi 覆盖仅 ≤10m，因此把设备固定在塔顶，塔顶部署 1 台 PoE 户外 AP，把望远镜的 Wi-Fi 桥接回校园网；学生可用 Seestar App 直连塔顶 AP，也可经 AP 桥接由校园网远程访问。进阶可启用 Seestar 官方"Telescope Network"远程功能或 ASCOM/Alpaca 对接 N.I.N.A.。
- **供电**：优先从校园路灯回路或科普角既有市电接一路独立空开 + 漏保；若现场无 220V，启用光伏降级方案（150W 单晶板 + 100Ah 锂电 + MPPT，预算已在表中列为备选）；再无则改为 12V 锂电 + 定时值守。

### 4.9 联动控制逻辑

核心原则：**罩与望远镜互斥动作**——观测中禁止关罩；开/关动作中望远镜锁定，避免机械干涉与抖动成像。

| 当前状态 | 触发条件 | 动作 | 迁移 |
| --- | --- | --- | --- |
| S1 闭合待机 | 收到开罩指令 且 环境安全 | 延时 1s，推杆伸出，两片球壳下滑 | 迁移至 S2 |
| S2 开罩中 | 行程到位（微动 + 计数双确认） | 锁定望远镜，延时 2s 后解锁 | 迁移至 S3 |
| S3 观测中 | 观测结束/定时到/雨感触发 | 望远镜回到 Home 位（可选） | 迁移至 S4 或 S5 |
| S4 关罩中 | 关罩行程到位 | 上电记忆状态写入 EEPROM | 迁移至 S1 |
| S3/S2/S4 | 雨感连续 3 次 / 风速 >8m/s / 温度 <-8℃ | 强制中止当前动作，立即关罩并告警 | 迁移至 S5 |
| S5 保护态 | 环境恢复正常且持续 5min | 回到 S4 关罩 | 迁移至 S4 |
| 任意 | 动作超时 60s / 电流 >3A 2s / 按下急停 | 立即断电退出，状态置 S6 并保持 | 迁移至 S6 |

**伪代码（控制核心）**：

```text
read sensors → safety_check()
  → 若 unsafe: close_cover();
  else if cmd==OPEN && state==CLOSED:
      state=OPENING; lock_scope(); push_open();
      wait_limit(ALL_OPEN, 60s) → if timeout: fault(); else state=OBSERVING; unlock_scope();
  if cmd==CLOSE || rain || wind:
      state=CLOSING; scope_home(); push_close();
      wait_limit(ALL_CLOSED, 60s) → save_state(); state=IDLE
```

### 4.10 防护、接地与安全

- **防护等级**：球壳 1.2mm 整体折边 + EPDM 胶条合缝 + 耐候胶；顶部设导水槽把水引到塔身外；控制盒 IP65；推杆本体 IP65。
- **电气安全**：二级浪涌保护 + 压敏电阻 + TVS + 保险丝；市电入口漏保；急停按钮常闭串在驱动器电源回路；光耦隔离限位信号。
- **防结露**：壳体内上部设防虫通风口 + 干燥剂，壳内温度低于露点 2℃ 时启动小功率加热（可复用 S50 Pro 机内加热元件思路）。
- **人身安全**：护栏仅设背向扇区；塔下 1.5m 设警戒区与警示牌；夜间调试须教师陪护；球壳下滑路径下方严禁站人（设光栅或地感提示）。
- **等电位**：两片铝壳、承力盘、塔身用扁铁连成等电位，接地极接地电阻 ≤10Ω。

## 五、创新点

- **结构创新**：把"半球穹顶"拆成两片 1/4 球壳沿竖直面对开并向下滑落，配合高基座形成"帽子往上戴、摘下往下滑"的极简机构——比传统天文圆顶少一整套旋转屋面与开合齿条，零件数与成本大幅下降。
- **视野创新**：下滑行程 = 罩半径 + 余量，保证开启后壳体整体位于赤道面以下，望远镜 0°~90° 全高度角零遮挡，彻底避开"半球罩挡脖子、挡低空"的老问题。
- **安装创新**：针对 S50 Pro"自带陀螺、不需赤道仪"的特点，取消全部转动底座，只做高刚性固定基座 + 中心下沉井道，把望远镜优化到赤道面高度以内，从而把罩半径压到 500mm（总高 1.6m）。
- **控制创新**："开罩—解锁—观测—归位—关罩"的状态机式联动，配合雨/风/温湿/光照多源感知与三重限位，实现无人值守式自动开关；并把状态机图纸化、可评审。
